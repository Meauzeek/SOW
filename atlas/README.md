# 随星录世界图志

打开 https://meauzeek.github.io/SOW/atlas/ 。无需构建，支持现代浏览器。

编辑模式支持国家边界、城市、名称、民生数据、图片与国旗国徽。网页版自动保存在当前浏览器；使用“导出项目”下载完整 JSON，“导入”可恢复。编辑不会直接提交到 GitHub。请在换设备或清理浏览器数据前导出备份。

“导出图片”可以选择地图内容、地图／地球仪／极地形状、画幅、PNG/JPEG 与 1920/3840/7680 像素或自定义分辨率（最多 4000 万像素）。

城市的“计入国内总数”控制已收录城市的人口、GDP 与数量汇总，含下属领土并按管辖国家计入。朗拉空马默认关闭，其余默认开启；全国人口预设独立于城市合计。

海平面情景：1986／现实 0 m，2025 +3.7 m，2039 +5.03 m（按作者两个时间锚点线性外推）。淹没与拟合海岸线基于 0.1° ETOPO 全球概览，不具备米级沿岸精度，也不模拟堤防、潮汐或地下连通。

数据来源与许可：界线为作者架空设定，基础地理为 Natural Earth 公共领域；高程为 NOAA ETOPO 2022；夜景为 NASA Black Marble；城市照片来源、作者和许可见 data/photo-sources.json 及各城市详情；生成城市图提示词见 data/generated-image-prompts.json；字体许可见 fonts 目录。朗拉空马现用作者指定图片。
